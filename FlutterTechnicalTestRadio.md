# Assignment
## Flutter Technical Test

### Summary

Feel free to approach this project with creativity and consider it as if you're working with a regular client seeking your expertise. Use third-party packages if necessary and make sure the project adheres to the outlined requirements.

### Task

Develop a Flutter app which gives the user the ability to listen to radio stations. The user should be able to see a list of all the radio stations and when the user clicks any of them it has to start playing. There must also be controls for the station playing, such as play/pause, volume up/down, etc. If the user likes the station he would be able to mark it as favorite and access it any time.

### Technical Requirements

- The app should pull the radio stations from any free API
- There should be clear instructions for how to run the application in the `README.md`
- The app should run on iOS or Android (no need to include other platforms)

### Things We Value At Labhouse

- Code legibility, efficiency, robustness, good architecture
- Originality and creativity in the UX / UI
- Extra feature set that showcase your skills

### Delivery

We expect you to spend no more than 8 hours on this test, but you are free to take as many days as you need to complete it.

Please upload all your code to a public GitHub repository and submit your delivery by sending us an email with:

1. The repository link
2. The platform to compile the code (iOS or Android)
3. The time it took to complete the test
4. A screen recording demo of the feature
